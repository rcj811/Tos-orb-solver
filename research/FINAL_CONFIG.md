# 驗證後的最終求解設定（2026-11-03）

## 設定
- 搜尋：beam search，8 方向，禁止立即回頭，狀態去重
- Beam 寬度：450（手機預設）；1500（高品質模式，約 3.5 倍時間）
- 步數上限：6x5=30、6x6=37、6x7=39、6x8=41（25 + 列數×2）
- Beam 多樣性：divK = 0.75（同一手指位置最多保留 beam/N×0.75 個狀態）
- 評分權重（solver3.cpp 的 W_V2）：
  adj 24.55, gap 12.73, diag 12.02, cleared 23.49, len 2.07(無作用), first 21.83, colors3 61.91, remUB 0, dead 0, near3 0
- 拼圖盾引導 SHW=150；多屬性盾 ELEMW=600

## 確認無效、已排除
- 兩組權重集成（各半寬）：combo −0.037（顯著變差）
- 第二輪路徑縮短：同一步內所有狀態步數相同，路徑長權重不影響排序 → 無效
- 新特徵 remUB / dead / near3：重新調參後在驗證盤上沒有勝過 v2，且首消顯著較差
