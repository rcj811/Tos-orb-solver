自轉珠 操作手冊

自動轉珠：浮動工作列、自動判斷盤面與關卡條件、越玩越準。

對應版本：build-95 以上
第一次使用工作列自動轉珠校：校正盤面 ＋：讀技能卡關：關卡條件問號盤符石類別App 設定常見問題
使用前請注意：自動操作遊戲可能違反遊戲的使用條款，帳號有被停權的風險，請自行斟酌使用。

第一次使用

安裝 APK。更新時直接覆蓋安裝，不要先解除安裝，否則學過的資料會清空。
打開「自轉珠」App，照畫面引導按「允許受限設定」，再按「開啟無障礙設定」，把自轉珠打開。
進入遊戲的戰鬥，畫面上方會出現浮動工作列。
按工作列的 校，把格線對齊盤面，按「儲存並學習」。
按 ▶ 開始自動轉珠，或按 轉 只轉一回合。

Android 11 以上才能自動截圖、自動轉珠。Android 10 以下只能用 App 裡的「手動模式」。

浮動工作列

編號按鈕功能
1⠿拖曳移動工作列（位置會記住）。點一下收合，再點一下展開。
2▶ 自動轉珠每回合自己轉：combo 最多，同樣 combo 時每組盡量剛好 3 顆；有記住的關卡就照它的條件轉。執行中變成紅色 ■，只有按 ■ 才會停。詳見自動轉珠。
3轉只轉這一回合：判斷盤面、讀 NUM 盾數字、套用記住的關卡條件，轉一次就停。
4＋讀技能卡：讀出王的技能並說明破解方法，自動設定條件；按「確定」後幫你關掉技能卡，接著轉這一回合。
5校校正盤面：對齊格線、修正認錯的珠子、標記特殊符石。盤面有認不出的珠子時變成橘色「校?」。
6關關卡條件：照這隻王的盾設定條件，按「完成」照條件轉一回合。
7⚙開／關上方的訊息列（設定會記住），關掉時按鈕變灰。
8✕連按兩下（2.5 秒內）關閉自轉珠。要再用，打開自轉珠 App 即可。
9訊息列一直顯示程式現在在做什麼（等盤面、計算中、轉珠中、動畫中、過場中），提示和警告也留在這裡。點一下可以清掉。關掉訊息列時，重要警告仍會用系統小訊息跳出。

▶ 自動轉珠怎麼運作

戰鬥中，每一回合

  1. 等盤面靜止：連續兩張截圖的盤面一樣。盤面本來就有三連也會照常轉。認不出的格子（問號）在 1/3 以內（6×5 盤 10 格）照樣轉，那些格子當障礙繞開。
  2. 動畫中不出手：攻擊、技能動畫時遊戲會把盤面蓋暗，程式會等盤面亮回來再轉。
  3. 判斷關卡：比對敵人畫面，認出記住的關卡就套用條件，「關」變黃色。自動轉珠不會自己去長按王，要讀技能請按「＋」。
  4. 讀 NUM 盾數字：NUM 盾的數字每回合會變，每回合都重新讀。
  5. 計算轉法：
    • 沒有關卡條件：combo 最多，同樣 combo 時每組盡量剛好 3 顆。
    • 有關卡條件：找全部條件都符合的轉法。
    • 設了「首消必消」：條件優先，先把要消的珠排好，做到就用最少步收手，不追求最大 combo。
    • 形狀盾、NUM、首消剛好 Combo 等精準條件：只走上下左右，不斜走，避免手指偏一點就多換一顆珠，把排好的形狀破壞。
  6. 先在畫面上顯示路徑，再自動拖曳。
  7. 問號盤：整盤被蓋成問號時，先移一格看顏色，再照條件轉完，見問號盤。

不會自己暫停

自動轉珠只有你按 ■ 才會停（或按「轉」「＋」「校」「關」✕ 這些按鈕時）：

  • 換場次、過場動畫、結算畫面：訊息列顯示「等待中」，繼續等下一個盤面。
  • 條件這盤做不到，例如 NUM 盾湊不到剛好的粒數：照最接近條件的轉法轉。

需要你處理時：提示＋震動，但不停止

下面這些情況，程式這回合不轉，會震動並在訊息列說明原因。你自己轉完這一回合後，程式會繼續自動轉下一回合。同一個提示 20 秒內不會重複震動。

  • 盤面全部是不能碰的珠子，一步都動不了。
  • 找不到「首消必消（全部消光）」的轉法，訊息會寫出目前最多能走幾步，以及怎麼調整。
  • 問號盤移了一格後，還是看不出顏色。

＋：讀技能卡與破解說明

在遊戲裡長按王，打開技能卡。
按工作列的 ＋：程式讀出技能文字，自動設定看得懂的條件，並跳出每個技能的規則、破解方法、自轉珠怎麼處理。
按「確定（自動關掉技能卡後轉珠）」：程式幫你點掉技能卡，等盤面出現後轉這一回合。
按「只配置、不轉」：一樣幫你關掉技能卡，只記住條件，不轉。

認得的技能包括：五屬傷害盾、五屬盾、電擊符石、觸電、NUM、首消、連擊零化、Combo 盾、十字／T 形／L 形限盾、風化、冰封、石化、拼圖盾。

校：校正盤面

操作效果
按住不放，震一下後再移動移動整個格線，對齊遊戲的盤面。一按下就滑動不會移動格線，避免點珠子時手指晃到。
拖右下圓點放大縮小格線。
點有「?」的珠子確認判斷正確。同一種顏色、有問號的珠子會一起確認，問號全部消失。
再點一次（或點沒有問號的珠子）換顏色：火 → 水 → 木 → 光 → 暗 → 心 → X → 火。每種顏色改一顆，同種的會自動跟著更新。
點到 X不知道是什麼的珠：不能碰、不能移動。按「儲存並學習」後，之後長得一樣的珠，路徑都會繞開。（黑白盤面沒辦法學 X）
長按珠子再放開切換符石類別：普通 → 強化 → 風化/黏腐 → 觸電 → 冰封/石化 → 起點GO → 自訂類別…，珠子右下角會出現類別標籤。
點右下角的類別標籤直接換到下一個類別，不用再長按。換回「普通」時標籤消失。
1自動偵測自動找盤面位置。
2列數切換盤面列數（5、6、7 列等）。
3重新截圖盤面變了（例如動畫播完）時重新截一張。
4＋類別遇到程式不認識的新符石，新增一種類別。見符石類別。
5儲存並學習儲存格線位置，並把你確認、修改過的珠子學起來。之後遇到同樣的樣子就會自動認出。

上方的「累計學習」是學過的格數，越多越準。校正完關掉後，橘色的「校?」會恢復成「校」。

關：關卡條件

按「關」時，條件每次都從空白開始，請照眼前這隻王的盾重新設定。設定好後按 完成：程式會記住這一關，並且照這些條件只轉這一回合。之後按 ▶ 自動轉珠遇到同一關，會自動套用。

面板怎麼點

  • 數值條件（Combo盾、首消Combo、首消屬性盾、NUM盾、形狀盾、同色組數）：點按鈕，正下方會列出全部選項，點一個就設定好，任何數值都只要 2 下。再點同一顆按鈕收起；長按按鈕＝回到「無」。
  • 開關（首消每組3顆、黏手路徑、火焰路徑、問號盤先移一格）：點一下切換。
  • 顏色列：點一色切換。
  • 衝突當場顯示：設定互相矛盾時，面板上方用紅字說明哪裡衝突，例如終點設在黑洞上。照這樣設定按「完成」不會轉。
  • 自動避開同色衝突：把某色設成「首消不能消」時，會自動從「首消必消」「同色組數」拿掉，反過來也一樣，並顯示「已把光從…拿掉」。

筆刷：點盤面上的格子

先點一支筆刷，再點下方盤面的格子；再點一次同一格就取消。同一格不能同時有的標記（拼圖盾／裂痕、必消／不消）會自動換成新點的那個。

筆刷意思標記會不會記住
拼圖盾標出盾的形狀。第一批要用同一種顏色把這些格子全部消掉。記住（同一關形狀固定）
燃燒(不碰)這些位置不能經過（燃燒、地獄火、雷射等地形）。記住
火焰區(終點)最後一步必須停在其中一格。記住
黑洞(不停)最後一步不能停在這格。記住
裂痕回合結束時停在這個位置的珠子不能被消除。可以經過，跟珠子種類無關。記住
起點(綠)／終點(紅)綠紅漩渦（起結有序）：一定要從綠格出發、停在紅格。漩渦圖案蓋住珠子也沒關係，程式會當成可以碰的珠。記住
必消(點珠)點到的這顆珠這回合一定要消掉，顯示藍色「必」。只用這一回合
不消(點珠)點到的這顆珠這回合不能消，顯示灰色「禁」。只用這一回合
不碰(點珠)點到的這顆珠不能碰：路徑不能經過、不能從它開始，顯示橘色「避」。它還是可以被旁邊的珠子湊成三連消掉。只用這一回合

盾與條件按鈕

可以同時設定好幾個條件（3 個以上也可以），程式會找全部都符合的轉法；這盤做不到時，照最接近條件的轉法轉。

按鈕意思可選數值
Combo盾整回合（含疊珠）至少 X combo。5～12
首消Combo第一批剛好 X combo。1～10
首消每組3顆第一批每一組都只能剛好 3 顆，不能有 4 顆以上連成一組。設定首消Combo 時自動打開，可再點一下關掉。開／關
首消屬性盾第一批至少 X 組屬性符石（心珠不算）。4～8
NUM盾第一批消除剛好 X 粒符石，疊珠不算。敵人身上顯示「NUM 數字」。10～24
形狀盾第一批要有 X 組指定形狀（5 粒同色）：十字、T 形、L 形。十字／T／L 各 ≥1～3 組
黏手路徑碰過的格子不能再碰（路徑不能重複）。開／關
火焰路徑不要重踩剛走過的格子。開／關
同色組數：各 N 組搭配下方「同色組數」顏色列：選到的每種顏色，第一批各消剛好 N 組、每組剛好 3 顆。各 1～3 組
問號盤先移一格只有部分格子被蓋成問號時也先移一格看顏色。整盤都是問號時不用開，程式會自動處理。開／關
顏色列意思
首消必消(全部消光)點選的顏色，第一批要把盤面上這種珠全部消光（數量是 3 的倍數就 3 顆一組，不是就用 4、5 顆一組湊）。選了這個，程式會條件優先：先排好要消的珠，不追求最大 combo。
首消不能消(第一批)點選的顏色，第一批不能消（例如「水連擊零化」）。疊珠不算。
同色組數(選2~5色)選 2～5 種顏色，第一批每色各消剛好 N 組（N 用「同色組數」按鈕設定），每組 3 顆，其他顏色不限。例如「光暗各 1 組」「木火光各 1 組」。
NUM 盾的數字每回合會變（例如 15 → 12 → 6）。按 ▶ 或「轉」時，程式每回合會自己讀敵人身上的數字。按「關」→「完成」則照你手動設定的數字。

下方三顆按鈕

  • 清除全部：把面板上的設定全部清空。
  • 取消：不儲存，關閉面板。
  • 完成：記住這一關的條件，並照條件轉這一回合。點珠標記只用這一回合，不會記住。

範例：光暗各 1 組＋首消剛好 4 Combo＋終點（共 6 下）

  1. 按 關。
  2. 「同色組數」顏色列點 光、暗（預設各 1 組）。
  3. 點「首消Combo」，選 4（「首消每組3顆」會一起打開）。
  4. 選「終點(紅)」筆刷，點盤面上紅色漩渦那一格。
  5. 按 完成。

範例：T 形限盾 ×2＋起點＋終點

  1. 按 關，點「形狀盾」選 T 形≥2。
  2. 用「起點(綠)」「終點(紅)」筆刷點出漩渦位置。
  3. 按 完成：程式只走上下左右，排出兩組 T 形，從綠格出發、停在紅格。

問號盤

有些王會把整盤珠子蓋成問號，看不出顏色。自轉珠的處理方式：

盤面每一顆都長得一樣，就判定是問號盤（不管程式把問號珠認成什麼）。
按住一顆珠移一格，手指不放開，等顏色出現後截圖辨識。
用「關」裡設定的所有條件規劃剩下的路徑，例如 NUM、首消不能消、起點／終點。
一路拖完才放手，整個過程算同一次轉珠。

按「轉」「完成」、▶ 自動轉珠都適用，不需要先在「關」打開。遇到 NUM 盾時會先讀敵人身上的數字。

注意：手指按著時遊戲的轉珠計時通常已經開始，所以這時計算時間會縮短，可走的步數比平常少一些。

符石類別

在校正畫面長按珠子切換類別（出現標籤後，直接點標籤換下一個），按「儲存並學習」後，之後看到同樣的樣子會自動認出。

類別（標籤）能不能碰消除方式例子
普通可以照常消除一般珠、種族符石
強化（強）可以照常消除強化符石
風化/黏腐（風）不能盡量消除風化、黏腐
觸電（電）不能必須消除觸電、電擊符石
冰封/石化（冰）不能不能消除冰封、石化、凍結；在校正畫面點成 X 的珠也會學成這類
起點GO（GO）可以照常消除，一定要從這顆開始轉GO 符石

新增自訂類別

遇到程式不認識的新符石：校正畫面按「＋類別」，或在 App 按「＋新增符石類別」。要設定：

  • 名稱：例如「刺血符石」。
  • 能不能碰：可以碰／不能碰（碰到會停止或受傷）。
  • 消除方式：照常消除、必須消除、盡量消除、盡量不要消除、不能消除。
  • 可勾選「必須從這顆開始轉」（像 GO 符石）。

新增後，在校正畫面長按那顆珠子選這個類別，再按「儲存並學習」。設定錯了可以在 App 的「修改／刪除自訂類別」修改或刪除。

自轉珠 App 設定

編號設定說明
1無障礙設定／允許受限設定第一次使用時開啟權限，程式會帶你跳到正確的設定頁並提示要按哪裡。

5品質標準或高。高品質找得更好但計算較慢。
6方向8 方向（含斜轉）或 4 方向（只有上下左右）。設了需要精準的關卡條件時，程式會自動只走上下左右。

常見問題

按 ▶ 不會轉？

  • 看訊息列寫什麼（訊息列關著的話按 ⚙ 打開）。
  • 「校」變成橘色「校?」：認不出的格子太多，按「校」，點問號確認或修正，再按「儲存並學習」。
  • 盤面還在動，或攻擊動畫讓盤面變暗：等一下，程式會等盤面靜止、亮回來再轉。
  • 格線沒對齊：按「校」重新對齊。

首消必消（全部消光）說沒辦法轉？

要消光的珠子多時需要走很多步。到 App 把「每步」調快、或「轉珠時間」調長，可以走更多步。

排好的形狀放手時被破壞？

build-79 以後，形狀盾、NUM 等精準條件只走上下左右，不會再斜走滑到旁邊的格子。

轉出來的路徑跟預覽不一樣？

手機跟不上速度。到 App 把「每步」調慢，路徑長度會自動調整。

怎麼確認裝的是最新版？

App 首頁、「關」面板第一行都會顯示 build 號碼。下載時請用帶號碼的檔名，例如 tos-orb-solver-95.apk，避免開到舊檔。

學過的資料不見了？

更新時先解除安裝會清空資料。之後請直接安裝新版覆蓋。

設定錯了怎麼辦？

App →「管理學習資料」，找到那一筆刪除。自訂類別在「修改／刪除自訂類別」。
